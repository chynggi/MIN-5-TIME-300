# 일기 작성 시스템 개편

이 프로젝트는 첨부된 이미지들과 요구사항을 바탕으로 일기 작성 페이지를 개편한 결과입니다.

## 새로운 기능들

### 📝 메인 일기 작성 페이지 (`/diary/new`)

#### 1. 이미지 추가 컴포넌트
- **기본 이미지 제공**: 봄, 여름, 가을, 겨울, 햇살, 밤, 비, 눈
- **사용자 이미지 업로드**: 커스텀 이미지 업로드 가능
- **미리보기 기능**: 선택한 이미지 즉시 확인
- 이미지를 설정하지 않을 시 자동으로 기본 이미지 설정

#### 2. 감정 & 음성 메시지 컴포넌트
- **감정 선택**: 8가지 이모티콘으로 감정 표현 (😊, 😢, 😡, 😎, 😐, 😴, 🤗, 😱)
- **음성 메시지**: 브라우저 내장 음성 녹음 기능
- **재생 기능**: 녹음된 음성 즉시 재생 가능

#### 3. 음악 설정 컴포넌트 (Spotify API 연동 준비)
- **음악 검색**: Spotify API를 통한 음악 검색
- **인기 추천곡**: 미리 선별된 인기곡 목록
- **미리 듣기**: 30초 미리 듣기 기능

#### 4. 작성 방식 선택
- **질문 제공 형식**: AI가 생성한 질문에 답하며 일기 작성
- **자유 형식**: 자유롭게 생각을 적는 일기 작성

#### 5. 일기 추가 설정
- **게시물 공개 범위**:
  - 비공개: 본인만 열람 가능
  - 전체공개: 커뮤니티 페이지 지도 API에 표시, 친구 열람 가능
  - 친구공개: 팔로우/팔로잉한 사람만 열람 가능
- **일기 공개 범위**:
  - 공개: 일기 내용이 공개
  - 비공개: 사진, 음성메시지, 음악, 일기제목만 표시, 내용은 모자이크 처리
- **날씨 추가**: 필수적으로 당일 날씨 추가 (해, 흐림, 비, 눈)

### 🤖 AI 질문 생성 기능

#### GPT/Gemini AI 활용
- **질문 생성**: AI가 개인화된 질문 제공
- **3단계 프로세스**:
  1. 질문 생성 화면
  2. 일기 작성 화면 (제목 + 답변)
  3. AI 요약 생성 화면

#### AI 요약 기능
- 작성된 일기를 AI가 분석하여 요약
- 감정 분석 및 핵심 키워드 추출
- 개인화된 조언 제공

### ✍️ 자유 형식 일기 작성
- **제목 + 내용**: 2000자까지 자유 작성
- **작성 팁 제공**: 효과적인 일기 작성을 위한 가이드
- **실시간 글자 수 표시**

### 📖 일기 상세 보기 페이지 (`/diary/[id]`)

#### 사용자 프로필 표시
- 프로필 아이콘과 닉네임 표시
- 작성 날짜와 시간 정보
- 감정 이모티콘과 날씨 정보

#### 멀티미디어 콘텐츠 지원
- **이미지**: 고품질 이미지 표시
- **음성 메시지**: 재생/일시정지 기능
- **음악**: Spotify 트랙 정보 표시

#### 권한 기반 기능
- **소유자 전용**: 수정/삭제 버튼
- **비공개 내용**: 모자이크 처리 표시
- **공개 범위**: 시각적 표시

## 🛠 기술 스택

### Frontend
- **Next.js 14**: React 기반 풀스택 프레임워크
- **TypeScript**: 타입 안정성
- **Tailwind CSS**: 유틸리티 우선 CSS 프레임워크
- **Web APIs**: MediaRecorder (음성 녹음), File API (이미지 업로드)

### 컴포넌트 구조
```
src/components/diary/
├── ImageUpload.tsx          # 이미지 업로드 및 기본 이미지 선택
├── EmotionVoice.tsx         # 감정 선택 및 음성 녹음
├── MusicSetting.tsx         # 음악 검색 및 선택 (Spotify)
├── WritingMode.tsx          # 작성 방식 선택
├── DiarySettings.tsx        # 공개 범위 및 날씨 설정
├── AIQuestionWriter.tsx     # AI 질문 기반 작성
└── FreeWriter.tsx           # 자유 형식 작성
```

### 타입 정의
```
src/types/diary.ts           # 일기 관련 TypeScript 타입 정의
```

## 📁 파일 구조

### 페이지
- `/diary/new` - 새 일기 작성 페이지
- `/diary/[id]` - 일기 상세 보기 페이지

```
public/images/
```

## 🚀 주요 특징

1. **모바일 우선 반응형 디자인**: 모든 기기에서 최적화된 경험
2. **직관적인 UI/UX**: 단계별 안내와 시각적 피드백
3. **실시간 미리보기**: 선택한 콘텐츠 즉시 확인
4. **접근성 고려**: 키보드 내비게이션 및 스크린 리더 지원
5. **확장 가능한 구조**: 새로운 기능 추가 용이

## 🔮 향후 개발 계획

1. **Spotify API 완전 연동**: 실제 음악 검색 및 재생
2. **위치 기반 서비스**: GPS를 활용한 장소 태그
3. **AI 개선**: 더 정교한 질문 생성 및 분석
4. **소셜 기능**: 친구와의 일기 공유 및 댓글
5. **데이터 분석**: 감정 패턴 및 성장 추적

## 💡 사용 방법

1. `/diary/new`로 이동하여 새 일기 작성 시작
2. 이미지, 감정, 음성, 음악 등 원하는 요소 추가
3. 질문 형식 또는 자유 형식 중 선택하여 작성
4. 공개 범위와 날씨 설정 후 저장
5. `/diary/[id]`에서 작성된 일기 확인 및 관리

이 개편된 일기 시스템은 사용자들이 더욱 풍부하고 의미 있는 일기를 작성할 수 있도록 돕는 것을 목표로 합니다.
